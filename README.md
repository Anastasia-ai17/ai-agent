# AI-Agent 🤖

Легковесный AI-агент на Python, который умеет анализировать и изменять файлы, а также выполнять код по текстовому запросу. Проект создан в рамках изучения принципов работы LLM-агентов и написания чистого, тестируемого кода.

## 🚀 Возможности (Features)
- **Чтение файлов:** Получение содержимого и метаинформации о файлах.
- **Запись и изменение:** Создание новых файлов и редактирование существующих.
- **Выполнение кода:** Возможность запуска Python-скриптов агентом.
- **Калькулятор:** Встроенный модуль для математических вычислений.

## 🛠 Технологический стек (Tech Stack)
- **Язык:** Python 3.12
- **Управление зависимостями:** [uv](https://github.com/astral-sh/uv)
- **Тестирование:** написаны тесты для ключевых функций
- **AI Модели:** Интеграция с готовыми LLM (через API)

## ⚙️ Установка и запуск (Installation & Usage)

1. Клонируйте репозиторий:

`git clone https://github.com/Anastasia-ai17/ai-agent.git`

`cd ai-agent`

2. Установите зависимости:

Так как в проекте используется менеджер пакетов uv, установка происходит одной командой:

`uv sync`

(Если у вас не установлен uv, его можно установить командой `pip install uv`)

3. Запуск:
   
Для старта агента выполните:

`uv run main.py "prompt"`
